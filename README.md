# Insight Medicolegal V2 — Lattice direction

A separate review concept, closely adapting the immersive Lattice layout from Allerton Digital into a restrained teal identity for Insight Medicolegal. Original Insight repository remains unchanged.

## Deploy with Cloudflare Workers

1. Connect this repository to a new Cloudflare Worker named `insightmedicolegalv2`.
2. Select the repository root, no build command, static assets directory `public`.
3. Or use Wrangler: `npx wrangler deploy`.

Expected URL after deployment (subject to the Worker and account configuration): `https://insightmedicolegalv2.webstaging.workers.dev`.

The preview carries `noindex,nofollow`, and is not intended for production. Validate all copy and legal/compliance notices before launch. Images currently use remote Unsplash URLs.
